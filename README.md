# Win Win Building Materials App — Version 1

A mobile-first Progressive Web App (PWA) for a building-materials business.

## Branding
WIN WIN
Together we grow

## Included in this first build
- Clean dashboard without daily/weekly/monthly sales clutter
- New Sales
- Separate Invoices
- Receipts
- Customers
- Products & stock
- Purchases menu
- Quotations menu
- Payments
- Deliveries menu
- Expenses menu
- Reports menu
- Staff menu
- Business settings
- Local/offline storage
- Printable branded invoices and receipts
- Ghana Cedi formatting
- PWA install/offline shell

## Important
This is a working V1 foundation. Data is stored locally in the browser/device. Before using it for live business records, connect the database/cloud sync layer and add authentication/backups.

## GitHub Pages
Upload the entire folder to a repository and enable GitHub Pages from the repository settings. Do not upload only index.html; keep css, js, icons, manifest.json and service-worker.js together.
